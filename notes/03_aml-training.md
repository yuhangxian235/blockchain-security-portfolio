# AML / 合规风控 详细训练模块（面向 KYT 交易监测岗）
> 不是速成课。目标是把"为什么要有合规、合规的人到底在做什么、加密货币有哪些洗钱与犯罪手法"讲透，并和你每天 4 小时的训练绑定。
> 教学法：每个概念都用我们追过的这起"授权钓鱼 → 100 万 USDT"案件对照。

---

## 第一部分：AML 为什么存在（监管逻辑）

### 1.1 问题从哪来
现金是匿名的，犯罪所得（贩毒、腐败、诈骗、勒索）要进入正常经济体系，就必须"洗白"成看起来合法的钱。于是各国立法要求**金融机构不能只当通道**，必须自己负责"知道客户、监测交易、报告可疑"。
- 法律义务的对象：**受监管机构**（银行、交易所、支付机构=VASP）。
- 分析师的角色：**不抓人、不破案**，只做"发现可疑 → 记录 → 上报 → 建议冻结/放行"。

### 1.2 洗钱三阶段（核心中的核心）
| 阶段 | 动作 | 目的 | 本案对应 |
|---|---|---|---|
| **Placement 放置** | 把赃钱第一次注入金融/加密体系 | 进入系统、远离犯罪现场 | 受害者 USDT 转入**共用归集热钱包** |
| **Layering 分层** | 制造大量交易、跨账户跨币种层层打散 | 切断来源线索 | 1inch 多跳换币 USDT→USDS→DAI→USDC→ETH、**剥皮链**切小块 |
| **Integration 整合** | 洗白后的钱回到正常经济活动（提现、买房、消费） | 让钱"变干净"可花 | 进交易所/混币器变现（本案未达，需标签库） |

> 面试金句：**Placement 是"进门"，Layering 是"绕晕追踪者"，Integration 是"花掉"。** 看到钱被混到归集钱包=放置；看到换币+拆分=分层；看到提币到 CEX=整合。

### 1.3 合规的几个支柱
- **KYC（Know Your Customer）/ CDD（客户尽职调查）**：注册、大额、提币时核实身份（姓名、证件、地址）。这是链上"伪匿名"的唯一破口——钱一旦进 KYC 的交易所，就能对上真人。
- **EDD（强化尽职调查）**：高风险客户（大额、政治敏感人物 PEP、被制裁地区、来源不明）走更严流程。
- **风险为本（Risk-based Approach, RBA）**：不搞一刀切，风险越高投入越多资源。本案判 **HIGH** 就是 RBA 的判断结果。
- **交易监测（Transaction Monitoring, TM）**：系统按规则/模型扫全部交易，可疑即抛告警。
- **制裁筛查（Sanctions Screening）**：每笔交易/每个地址对照 OFAC 等名单，命中即冻结上报。

## 第二部分：合规分析师的真实工作流

告警进来后，分析师按这个闭环走：
1. **受理告警**：看系统给的风险标签和命中规则。
2. **主体识别**：涉及哪些地址？EOA 还是合约？是不是新地址？有没有已知标签（赃款、制裁、黑客）？
3. **行为分析**：钱从哪来、到哪去、时间间隔、金额特征、跨币种/跨链行为是否"合理"。
4. **风险定级**：低 / 中 / 高，写出理由。
5. **处置（Disposition）**：
   - 关单（合理行为，如正常 DeFi 操作）；
   - 继续监控 / 要求补充材料；
   - **冻结（hold / freeze）**；
   - **上报 SAR/STR**。
6. **写工单/报告**：客观、可追溯、不含臆测（你写的 report.md 就是这个）。

### 2.1 两个必背实操问答
**Q1：钱碰到 OFAC 制裁地址，第一动作？**
- 立即**冻结/扣留**该资金，不转出、不退回、不发生新交易（实务：筛查系统自动 hold，分析师复核）。
- 报内部合规官/法务；按 OFAC 要求在 **10 个工作日内**报告被冻结财产；**解冻只能由 OFAC 书面授权**。
- **绝不通知对方**；保留全部记录。严格责任——不知情也要冻+报，主动上报可减责。

**Q2：为什么不能把调查进展告诉客户？**
- 这叫 **tipping-off（通风报信）**，本身违法。
- 理由：对方可能涉案，得知后会转钱/毁证/跑路；会破坏执法跟踪；泄露 SAR 可被处罚；你尚未定性，贸然告知还涉及保密与名誉风险。
- 正确做法：对客用中性话术（"需补充风控验证"），信息按 need-to-know 内部流转，该报监管就报监管。

### 2.2 SAR / STR
- **SAR**（美国 Suspicious Activity Report）/ **STR**（多数司法区 Suspicious Transaction Report）：研判可疑后向监管提交的正式报告。
- 安全港（Safe Harbor）：善意提交的分析结论受保护，不被客户起诉。
- 铁律：保密，不得向被调查方透露；按规定时限提交。

## 第三部分：加密货币犯罪类型学（每种记一个链上特征）

| 类型 | 手法 | 链上特征（你要能一眼认出） |
|---|---|---|
| 授权钓鱼盗币 | 骗签无限 approve，再 transferFrom | 新钱包→恶意合约 approve(max)，几秒后第三方 transferFrom（**本案**） |
| 私钥泄露 / 签名钓鱼 | 诱导签恶意交易或 Permit | 签名哈希与实际转账不一致；Permit 签名重放 |
| Rug pull | 项目方抽走流动性 | LP 流动性被一次性转入项目方地址、快速换币 |
| 退出骗局 / 假交易所 | 卷用户资产跑路 | 大量用户地址→少数归集钱包→换币→提现 |
| 杀猪盘（Pig butchering） | 社交诱导投资 | 分批小额入金→归集→批量换币出金 |
| 勒索软件 | 加密文件索要赎金 | 固定收款地址、金额固定、很快换匿名币/混币 |
| 混币器 | Tornado / Blender 切断追踪 | Tornado 固定面额 0.1/1/10/100 ETH；存款取款间隔 |
| 链上洗白手法 | 归集、DEX 换币、跨链、剥皮 | 多受害者归集；多跳稳定币；每跳切半；反取证假币/粉尘 |

### 为什么"伪匿名"不等于匿名
地址本身匿名，但：①交易所 KYC 把地址绑到真人；②链上地址可通过 gas 资金方、nonce 连续性、共同操作聚类；③一旦一端被识别，全链可追溯。所以洗钱者越折腾（换币、剥皮、混币），链上特征越规律，越容易被规则抓到。

## 第四部分：监管地图（高层了解，不背法条）
- **美国**：BSA/AML、FinCEN 指引、OFAC 制裁名单（Tornado Cash、Blender.io、Garantex、Sinbad 等被点名）。
- **欧盟**：MiCA（加密资产市场监管）、AMLD5/AML 指令（含 tipping-off 禁令）。
- **亚洲**：香港 VASP 发牌制度、新加坡 MAS 指引。
- **中国**：了解境内对虚拟货币交易炒作的监管边界即可。
- 你大概率投递的雇主：交易所海外合规/风控、链上情报/风控厂商（慢雾 MistTrack、派盾 PeckShield、Chainalysis、TRM 类）、支付与合规科技公司。
